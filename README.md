# 💬 Chattie

**Chattie** is a real-time **AI chat application** built with **React**, **Node.js**, and **Socket.io**.  
It allows users to chat with an AI powered by **Google Gemini API** — all in real time, with a smooth and responsive UI.

---

## 🚀 Features

- ⚡ Real-time communication with **Socket.io**
- 🤖 Smart responses generated by **Gemini AI**
- 🔄 Live message updates (no page reload)
- 💬 Clean and modern React interface
- 🧩 Modular Node.js backend
- 🌐 Simple setup with `.env` configuration

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-------------|
| **Frontend** | React, Axios, Socket.io Client |
| **Backend** | Node.js, Express.js |
| **Real-time Engine** | Socket.io |
| **AI Model** | Google Gemini API |
| **Styling** | Custom CSS
| **Environment** | dotenv |
